# Getting Started

This repository contains Python code organized into three main areas:

## Notebooks

Interactive Jupyter notebooks demonstrating various concepts. Open `.ipynb` files with Jupyter Notebook or Jupyter Lab.

## Python Modules  

Standalone Python scripts in `python_modules/`. Can be imported and used in your own projects.

## Writings

Markdown documentation explaining concepts, approaches, and lessons learned.

## Running Locally

```bash
pip install jupyter
jupyter notebook notebooks/
```

The repository is also configured for GitHub Pages to display content as a website.
